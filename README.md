# li_test_repo

Simple event hub web application.

Run locally:
- npm install
- npm start

User features:
- Browse events, search and filter
- View details and register in real-time
- Recently viewed stored in localStorage
- Offline browsing of cached pages and events via Service Worker

Admin:
- Navigate to /admin.html
- Password: admin (can be overridden with ADMIN_PASSWORD env var)
- Create, edit, and delete events with live updates
